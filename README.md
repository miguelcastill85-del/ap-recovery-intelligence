# AP Recovery Intelligence — Synthetic Evidence Room v3

Premium interactive synthetic due-diligence sample.

## Core controls
- No unsupported confidence percentages.
- HIGH / MEDIUM / REVIEW are evidence tiers, not probabilities.
- Identified, confirmed and recovered value are separate.
- Counterevidence is displayed alongside supporting evidence.
- False-positive controls are deliberately demonstrated.
- Source rows can be compared side-by-side.
- No client data and no real customer case study.

Open `index.html` in a browser. No server, API, package manager, database or paid service is required.
